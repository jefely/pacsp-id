# 方案一：纯筛选对照（无需写作）

**目的**：把"人类筛选"这一变量**单独**测出来，且**不需要你写文章**。
**设计**：同一题面下两个模型的稿件，你选更好的那一篇。

---

## 一、为什么这个设计是干净的

论文的判定轴是**"人是否对 AI 输出施加了筛选"**。原三臂设计里，
A 臂（人类独写）把"作者身份"和"筛选"混在一起，而且需要你写 31 篇。

本设计把两者拆开：

| 臂 | 文本来源 | 是否有人类筛选 |
|---|---|---|
| `gaokao_chosen` | **模型生成**（你选中的那篇） | ✅ 有 |
| `gaokao_unchosen` | **模型生成**（你落选的那篇） | ❌ 无 |

**两臂都是机器写的**，所以：

> **两臂之间任何 C_T 差异都只能来自"筛选"这一步——作者身份被完全固定。**

这是本批素材能给出的**最干净的对照**，且完全避开了"写作水平"问题。

## 三、你的任务：31 次二选一

打开 `data/gaokao_selection/001.txt` … `031.txt`，每份含：

```
【题面】   ……
【候选一】 ……   （NNN 字符）
【候选二】 ……   （NNN 字符）
```

**读完后在心里判断哪一篇更好**，不要参考长度——**两篇长度已匹配**。

选择单的三项控制：

| 控制 | 做法 |
|---|---|
| **长度** | 两稿都裁到句边界、同一上限（均值 764 vs 766 字符） |
| **位置** | 每题随机决定哪稿在"候选一"（31 份中 r1 在前 12 份） |
| **题面** | 同一题，两稿都基于它 |

所以你无法从长度或位置推断，只能凭内容判断。

## 四、怎么记录

1. 复制模板为 `_choice.txt`：

```powershell
Copy-Item D:\myproject\PACSP-ID\data\gaokao_selection\_choice.template.txt `
          D:\myproject\PACSP-ID\data\gaokao_selection\_choice.txt
```

2. 在每题行后填 `A` 或 `B`（也可写 `1`/`2`）：

```
001 A
002 B
003 B
```

3. 校验与构建：

```bash
cd PACSP-ID
python scripts/pacsp_selection.py --check     # 看已填/缺哪些、选了哪一稿
python scripts/pacsp_selection.py --build      # 分臂 + 跑流水线
```

**不必一次填完。** `--check` 会报出已填数量与缺失题号；
`--build` 会跳过未填的题，用已填的部分出结果。

## 五、`--build` 会做什么

1. 按 `_key.json` 把每题的选中稿 / 落选稿分别写入
   `data/gaokao_chosen/` 与 `data/gaokao_unchosen/`
2. 写入 `_PROVENANCE.json`，记录**你选的稿来自哪个模型**（qwen 还是 r1）
3. 跑：

```
python scripts/pacsp_build.py --innov --target centroid \
       --datasets gaokao_chosen gaokao_unchosen --out records_centroid/
```

## 六、结果应当怎么读

**核心量**：

```
筛选效应 = C_T(gaokao_chosen) / C_T(gaokao_unchosen)
```

| 结果 | 含义 |
|---|---|
| ≈ 1.0 | 你的选择与 C_T 无关——**C_T 测不到人类的筛选偏好** |
| > 1.0 | 你倾向选 C_T **更高**的稿 |
| < 1.0 | 你倾向选 C_T **更低**的稿（更平顺的文本） |

**三种结果都有价值。** 若是 ≈1.0，那是对 §8.5 判定表的**直接反证**——
说明该度量无法反映人类的质量判断。这种负面结果与正面的同样值得报告。

**必须同时检查的混淆**：

| 混淆 | 检查方式 |
|---|---|
| **模型偏好** | `_PROVENANCE.json` 里 `chosen_model_counts`。若你压倒性地选某一模型，测的是"模型差异"而非"筛选" |
| **长度残留** | 两侧已匹配，但 `--build` 会打印两臂均值，若差异 >5% 需注意 |
| **结构** | qwen 与 r1 的句长/句数分布不同，若两臂结构差异大，C_T 差异可能来自结构 |

〔整理者按〕第三项是关键：**如果两臂主要差异是"你选了哪个模型"，那么本实验
测的是模型间风格差异，而不是筛选效应。** 为降低这一风险，若你发现自己
高度一致地偏爱某一模型，请在记录里注明——那本身就是重要发现，
但不应表述为"人类筛选导致 C_T 变化"。
