# 高考作文同题三臂语料：设计、写作规范与运行方式

**目的**：为论文 §10.5 提供**唯一同题三臂**对照——公开语料里不存在的东西。
**同题的好处**：31 道高考作文题是公共知识，三臂共用同一题面，**主题被完全固定**，
因此差异只能来自"谁写的"与"人是否对 AI 输出施加了筛选"。

---

## 一、三臂定义

| 臂 | 目录 | 产法 | 关键点 |
|---|---|---|---|
| **A 人类独写** | `data/gaokao_human_only/` | **人从题面自己写**，不借助任何模型 | 无 AI 参与 |
| **B AI 原始** | `data/gaokao_ai_raw/` | 本地 `qwen2.5:7b` 一次性生成，**未加修改** | 无人类筛选 |
| **C 人类修改 AI** | `data/gaokao_human_curated/` | 人在 B 的草稿上**修改定稿** | **curation** |

题面同源，所以：

- A vs C 分离**"人是否对输出施加筛选"**
- B vs C 分离**"人是否介入修改"**
- A vs B 分离**"作者是人还是模型"**

论文 §10.5 的判定需要的是 A vs C 这一对比。

---

## 二、写作规范（决定实验是否可用，务必遵守）

**最要紧的一条：三臂字数尽量对齐。**

论文用到的度量 `C_T = Σ μ_k · δ_k` 累加**未归一化**的嵌入距离，
**文本越长 C_T 通常越大**。前期整理中已两次遇到这个混淆：

- 历史文本代理臂：唐诗最短（72 字节/首）却 C_T 最高——后来发现是语义离群
- HC3 原始数据：人类 ~150 字符 vs ChatGPT ~450 字符，**不匹配则完全不可比**

所以：

| 项 | 要求 |
|---|---|
| **篇幅** | 目标 **800–1000 字**（AI 臂均值约 960 字，见下） |
| **偏差容忍** | 三臂篇均字数差距 **控制在 ±10% 以内** |
| **文体** | 议论文，自拟标题 |
| **语言** | 现代汉语书面语 |

**其次是结构对齐**：AI 常在相同字数下写出**更多、更短的句子**
（HC3 实测：句数 1.19–1.35×，句均长 0.60–0.64×）。
而 C_T 对句边界敏感——句越多、跳变越多、C_T 越高。
因此 A、C 两臂**不要刻意写成"多短句"或"多长句"**，按你自然的写法即可，
但请在实验记录里注明（见第四节），以便必要时统计控制。

**C 臂的修改要求**：**真实修改，不是润色**。
逐段读 AI 草稿，把与你的判断不符之处改掉：论点、论证、例子、语气、结构都可动。
保留多少由你决定，但**不要为了"改得多"而改**——本臂要测的是
"人施加了筛选"这个事实，而不是修改幅度。

**A 臂不得参考 B、C**：请先写完 A 臂，再看 AI 草稿。
隔离要求见第五节。

## 三、文件命名

每个臂 31 个文件，按题号一一对应：

```
data/gaokao_prompts/001.txt          ← 题面（已就位）
data/gaokao_human_only/001.txt       ← A 臂第 1 题
data/gaokao_ai_raw/001.txt           ← B 臂（已生成）
data/gaokao_human_curated/001.txt    ← C 臂第 1 题
```

**题号必须对齐**——`pacsp_gaokao.py --edit-distance` 就是按题号配对，
计算"人把 AI 草稿改动了多少"。

## 四、实验记录表（建议填写）

请在 `data/gaokao_ai_raw/_session.json` 记录（可留空，但**不要留假数据**）：

```json
{
  "writer": "<你的标识，可匿名>",
  "model_used_for_reference": "无 / 仅用于 C 臂修改",
  "a_arm_order": "先写 A，后读 B",
  "notes": "任何你认为会影响可比性的情况"
}
```

〔整理者按〕尤其记录**你是否在写 A 臂时看过 AI 文本**。
若看过，A 臂就不再是"人类独写"，整个对照失效——这是必须如实登记的一项。

## 五、运行方式

```bash
cd PACSP-ID

# 看进度
python scripts/pacsp_gaokao.py --status

# 看三臂对齐情况（按题号）
python scripts/pacsp_gaokao.py --status

# 计算"人改动了 AI 草稿多少"
python scripts/pacsp_gaokao.py --edit-distance

# 跑流水线并出对照表
python scripts/pacsp_gaokao.py --build
```

`--build` 会调用：

```
python scripts/pacsp_build.py --innov --target centroid \
       --datasets gaokao_human_only gaokao_ai_raw gaokao_human_curated \
       --out records_centroid/
```

**三臂必须用同一 `--target` 与同一输出目录**，否则不可比。

## 六、AI 臂（B）的登记

| 项 | 值 |
|---|---|
| 模型 | `qwen2.5:7b`（本地 Ollama） |
| 参数 | `temperature=0.8, top_p=0.9, num_predict=1600, seed=1000+题号` |
| 生成 | 每题**一次**，不成稿、不重试 |
| 后处理 | 仅去除可能的标题行前缀，正文未改 |
| 来源登记 | `data/gaokao_prompts/_index.json` |

**题面来源**：历年高考语文作文题（公共考试题目），
`_index.json` 记录每题的年份与卷别，可回查。

## 七、这份语料的局限（预先声明）

1. **A 臂只有一人**：若 31 篇全部由同一人写，则"作者效应"与"个体风格"不可分。
   多写者参与会更好，但单写者仍强于历史文本代理臂（后者连时代都不同）。
2. **题面体裁单一**：全部为议论文，结论不能外推到其他文体。
3. **篇幅仍可能不齐**：即便按第二节要求控制，人工写作的长度分布通常比模型更散。
   收尾脚本会报出三臂的字数分布，**若偏差超过 ±10% 应在论文中如实说明**。
4. **C 臂的修改幅度因人而异**：`--edit-distance` 会报出相似度，
   若相似度普遍很高（如 >0.95），说明修改过轻，curation 效应可能测不出来。
