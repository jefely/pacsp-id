### 3.1 单调性检验（论文核心预测）

```
μ_k 均值升序 : poem(0.1272) < lyrics(0.1677) < techdoc(0.3352)
C_T   升序   : poem(1.90) < lyrics(2.13) < techdoc(7.40)
```

两序列**完全同序**，与论文 §5.3「歌词振荡、技术文档建构」及 ICML 2026
「情绪树复杂度随认知负荷递增」的方向一致。诗歌的 μ_k 均值最低（0.1272），
而其情绪树深度最高（2 层，其余两域为 1 层）—— 短文本的情绪表征更集中于少数
通道，反而形成更深的层级，这与 §7.2「层级越深意味着标记操作越密集」并不矛盾：
深度由**通道间条件概率结构**决定，而非由序列长度决定。

## 4. §7 瑟-树耦合实测

`C_T_ext = C_path + C_jump + C_depth + C_bias`，其中 `C_depth = 0.1·d_tree`，
`C_bias = 0.05·B_tree`。

| 域 | C_path | C_jump | C_depth | C_bias | C_T^ext |
|---|---|---|---|---|---|
| poem | 1.841087 | 0.053917 | 0.200000 | 0.000000 | **2.095004** |
| lyrics | 2.126140 | 0.000000 | 0.100000 | 0.000000 | **2.226140** |
| techdoc | 6.922489 | 0.475718 | 0.100000 | 0.000000 | **7.498207** |

校验：`C_path + C_jump` 与归档 `C_T` 精确相等（三域全部成立），说明瑟-树耦合是
在原有 C_T 之上的**可加扩展**，未篡改既有分解。

### 4.1 C_bias 与跨域群体熵

将三域共 90 个样本按域分组作为伪身份群体，联合情绪树的偏见熵为
**0.027757 bit**，对应 `C_bias = 0.001388 Se`。数值小是因为三域的情绪分布
本就重叠度低，域间不存在「被系统性误标记到单一通道」的压缩现象。
真实身份群体标注下该分量才具备论文 §7.3 的判别力。

## 6. 必须由上游补齐的两个前提

### 6.1 缺少机器书写对照组 —— §8.5 结论列无法判定

**这是本次分析最重要的结论。** 论文 §8.5 的判定表要求对比「人脑式解耦—重组」
与「当前 LLM 组合式重组」。当前三个数据集**全部是人类书写文本**：

- 三个域的 `S_int` 全部为**负值**（诗歌 -0.4585、歌词 -0.1521、技术文档 -0.2282），
  即 `ΔC_T` 与 `ΔA_goal` 负相关；
- 按 §8.2 的 `C_sel = max(0, S_int)·0.5`，`C_sel` 恒为 0；
- 按 §8.5 规则，三者都**不应**被判定为「人脑式解耦—重组」。

这说明：**IDL 的判别力只能通过人/机对照来检验**。同一框架下需要机器书写的
同类语料（诗歌、歌词、技术文档各 31 篇）才能构成有效对照组。
在没有对照组的情况下，任何「人脑 vs LLM」的结论都缺乏依据，本报告不作此判定。

### 6.2 A_goal 的语义前提

论文 §8.2 定义 `S_int = Corr(ΔC_T, ΔA_goal)`，`A_goal(t) = cos(v_t, target)`。
该式要求 `target` 是**一个有意图含义的目标**。归档记录中只有文本嵌入，
不含「这个序列在朝什么目标演化」。

当前提供两种模式：

| 模式 | target | S_int/DRI/C_sel | 语义 |
|---|---|---|---|
| `none`（默认） | 无 | 记为 `null` | 不伪造目标，避免无意义相关性 |
| `centroid` | 本域嵌入质心 | 可算 | 衡量「本域一致性」，非「意图推进」 |

**`centroid` 也不是意图目标**：它无偏但语义弱。真正的 `S_int` 需要显式目标定义，
例如「完成一篇技术文档」这一意图对应的目标向量。

```bash
# 默认：不定义目标
python scripts/pacsp_build.py --innov --datasets lyrics techdoc poem

# 质心标定：目标=本域嵌入质心
python scripts/pacsp_build.py --innov --target centroid --datasets lyrics techdoc poem
```

### 6.3 group_labels（身份群体标签）

`C_bias = β·B_tree` 需要「身份群体 → 情绪通道」的误标记熵。当前三域均为
单一来源的连续快照，不含身份群体标注，与论文 §6.3「单作者范围」局限对应。
机制已验证可用（跨域伪群体给出 0.027757 bit）。
