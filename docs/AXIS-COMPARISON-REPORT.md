## 3. 判别力检验（核心负面结果）

对每个指标检查「自主生成 > 人机交互」在三个域上是否方向一致。
方向一致（0/3 或 3/3）才具备判别力：

| 指标 | 自主生成>人机交互的域数 | 方向一致 | 可判别 |
|---|---|---|---|
| C_T | 2/3 | **否** | 否 |
| μ_k | 2/3 | **否** | 否 |
| δ_k | 2/3 | **否** | 否 |
| 情绪树深度 | 1/3 | **否** | 否 |
| C_DMN | 2/3 | **否** | 否 |
| C_ECN | 1/3 | **否** | 否 |
| C_SN | 1/3 | **否** | 否 |

| H_switch | 1/3 | **否** | 否 |
| 切换次数 | 1/3 | **否** | 否 |
| Aha 个数 | 2/3 | **否** | 否 |

**没有任何指标在「人机交互」与「自主生成」之间保持方向一致。** 唯一接近的是 Aha 个数（自主生成在 3/3 域更多）
与 S_int（自主生成在 3/3 域更低，但两者全为负值，差异无实际意义）。

这意味着：当前 IDL 指标主要刻画**内容域特性**，而非**书写主体特性**。
域间差异（C_T 从 1.9 跨到 7.4，约 4 倍）远大于两条轴之间的差异（约 7%–21%）。

## 4. §8.5 判定结果

| 域 | 人机交互判定 | 自主生成判定 | 是否符合预期 |
|---|---|---|---|
| poem | 介于两者之间 | 介于两者之间 | ❌ 否 |
| lyrics | LLM+响应余量（外部连续性增强） | 当前LLM组合式重组 | ✅ 是 |
| techdoc | 介于两者之间 | LLM+响应余量（外部连续性增强） | ❌ 否 |

三组配对中仅**自主生成歌词**落入预期类别（「当前 LLM 组合式重组」）。

原因分析：该判定来自 `S_int ≤ 0.1 and DRI ≤ 0.5 and χ_innov ≤ 0.3` 的条件，
而自主生成歌词恰好 `χ_innov = 0.0000` 满足阈值 —— 也就是说，
命中更可能是**阈值边界的偶然**，而非机制性判别。

### 5.2 一个必须报告的负面结果

`S_int` 在两种嵌入下**符号翻转**：

| 域 | bge S_int | Keci S_int | 变化 |
|---|---|---|---|
| lyrics | -0.1521 | +0.4125 | 符号翻转 |
| techdoc | -0.2282 | +0.2977 | 符号翻转 |

由此技术文档的判定在两个嵌入下不一致（bge「介于两者之间」vs Keci「LLM+响应余量（外部连续性增强）」）。

`S_int = Corr(ΔC_T, ΔA_goal)` 是路径增量二阶差与目标对齐增益的相关系数，
在 30 个样本上信噪比低，对嵌入空间高度敏感。**该系数目前的测量稳定性
不足以支撑判定用途**，这是 §8.4 需要修订之处。

## 6. 结论与建议

### 6.1 已验证成立

1. C_T 精确可复现（1e-9 内），变点一致，L1–L6 全部通过
2. `μ_k` 均值随认知负荷严格递增（0.1272 < 0.1677 < 0.3352）
3. §5.2 的跨嵌入量级偏差（1.43–1.51）与排序一致性成立
4. 瑟-树耦合可加性成立（`C_path + C_jump` 精确等于原 C_T）
5. 三域情绪树可构建，诗歌深度最高（2 层）

### 6.2 需要修订

1. **§8.4 `S_int` 定义**：对嵌入空间不稳健，符号可翻转
2. **§8.5 判定表**：现有指标在两条轴之间没有任何一个保持方向一致，判别力不足以支撑该表
3. **§8.2 `C_ECN`**：依赖真实目标定义，当前质心标定语义偏弱
4. **§7.3 `C_bias`**：需身份群体标注，当前未激活

### 6.3 建议的下一步实验

1. 扩大样本量（每域 ≥200 篇），提高 `S_int` 的统计稳定性
2. 引入显式目标定义（如标注「意图达成点」），替代质心标定
3. 使用多模型（不同规模/家族）生成自主生成语料，检验模型规模效应
4. 收集多作者人机交互语料，分离作者风格效应
5. 对 `S_int` 与 `DRI` 做 bootstrap 置信区间估计，给出显著性判据
